# Agent 输出后人工修改的回滚保护

更新：2026-10-15。

## 逐文件提案

公开 proposal.undo / undo_all 强制接收 review_token，校验持久化令牌、文件结束摘要、HEAD 和执行前脏文件清单。缺令牌、伪造令牌、缺开始基线均拒绝。collect 生成令牌；刷新列表或新建管理器不覆盖旧摘要。现行实现已堵住无令牌回滚入口。

新轮次具备完整 S/E 时，逐文件 undo 走统一选择性撤销服务，以 E 为祖先将当前 C 与执行前 S 合并，保留执行前人工内容及执行后不冲突的编辑。冲突输出工作区外产物，不写业务文件；解决后显式重审。二进制只允许未发生后续变化时精确恢复，符号链接拒绝。缺少完整 S/E 的旧版提案继续拒绝执行前混写、执行后人工修改及二进制，不以 HEAD 猜测撤销目标。

## 整轮快照

整轮回退已改为 review_checkpoint → 带令牌 restore_checkpoint。恢复执行前文件和真实暂存区，不再使用 checkout/clean/reset 组合。Agent 新增并暂存的文件可正确移除，人工原有暂存内容和未跟踪属性保留。结束摘要不可重写，暂存区变化也属于冲突；快照引用按实际 worktree 隔离。

部分失败或进程退出后保留进度与备份，检查后可用新令牌继续已知操作；只处理匹配自身记录的 index.lock。详细流程见[工作区创建与回退](WORKSPACE_RECOVERY_AND_ROLLBACK.md)。

## 安全边界

回退与 Agent、后台任务共用工作区 OS 锁，并先检查遗留资源和未知任务。编辑器不遵守锁，检查与 replace/unlink 之间仍有竞争窗口，多文件操作不是事务；不能发现所有已被覆盖且未留下痕迹的极短写入，仍需备份和人工核对。

默认不备份 .env 等 Git 忽略文件，也不删除它们；目标被忽略文件占据时拒绝覆盖。远程 API、推送、数据库副作用需人工补偿。executions.db 提供核对线索，不是补偿器，也不能观察 Shell 内部所有远程行为。

## 已交付与后续路线图

详细设计、入口与验收标准见[三方合并与选择性撤销](SELECTIVE_UNDO_PLAN.md)。快照仅保留最近一轮，新基线成功保存后释放旧引用；冲突和部分恢复阻止提前释放。Git 对象并非立即物理删除。

- [x] **三方文本合并撤销**：保存原始 S/E 内容，以 E 为共同祖先，将 C 与 S 合并；冲突不自动应用，修改解决产物后重新审阅。
- [x] **按文件撤销本轮增量**：以 S→E 确定范围，撤销其反向变化，不以 HEAD 为目标；选择性恢复对应 index 条目，保留未选中文件。
- [ ] 任意历史轮次、按 hunk 撤销、后续人工暂存的独立合并，以及严格作者归因，仍需另行设计。

验收覆盖执行前/后人工修改、同位置冲突、新增/删除、换行符、二进制、暂存区、跨 worktree 及真实进程退出。文件内容校验与事件/恢复证据共同验证，不以事件健康代替内容正确性。
